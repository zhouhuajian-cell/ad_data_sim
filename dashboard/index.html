📖 使用说明（第一次看这里）
  1. 总览：只看不用点——显卡/内存/磁盘状态；最下面进度条 = 渲染任务完成了百分之几，5 秒自动刷新。
  2. 干活按顺序：① 环境核查（全 PASS 才继续）→ ② 编译 UE5（1~3 小时，只点一次）→ ③ 任务生成 → ④ 启动渲染 → ⑤ 跑后处理 → ⑥ 打包数据集。改过任何脚本后先点「链路自检」，全 PASS 再跑正式批次。
  3. 每个按钮点下去 = 启动一个"作业"：输出实时显示在对应卡片下方的黑框里，也可在下方"作业控制台"点开任意作业看；黄字=跑着、绿字=完成、红字=失败。
  4. 作业控制台：点某一行看它的输出；选中后可"杀掉"（中断）。同类作业在跑时不能重复点，会自动提示。
  5. 日志：出问题先看 batch.log（渲染日志）、capture_errors.log（单帧错误）。
  6. 配置：所有文件路径都在这，一般不用动；改完点"保存配置"立即生效。
  7. 渲染/编译这类长任务，关掉网页也照样跑，回来刷新就能看到进度。
