# GND 路面运动估计实验（2026-11-23）

实验工具：`gnd_motion_diagnostic.py`。这是独立诊断程序，未接入平台渲染或训练导出。

方法：按原始帧时间排序，读取道路和目标掩码，排除动态目标后对路面角点做前后向光流；使用相机内外参映射至近似地平面，RANSAC 筛选并拟合二维刚体变换，再投影回图像。比较相邻帧和首帧参考的车道线分割相符情况，掩码缺失或质量不足时拒绝。结果中的 `preview_candidate_only` 只是通过启发式筛选，不等于世界坐标准确或可用于训练。车道线分割不是经验证的真值；平面、畸变和遮挡同样影响结果。

服务器：`/data/avsynth/experiments/gnd_motion_20261123/`，每个片段对应一个 JSON。使用 `/opt/ad_mining/venv/bin/python` 运行，示例：

```bash
/opt/ad_mining/venv/bin/python /data/avsynth/experiments/gnd_motion_20261123/gnd_motion_diagnostic.py \
  --batch 02_HS5-001_20260506 --clip 1778023487.589 \
  --output /tmp/gnd_motion_report.json
```

四个 20 帧片段结果：`1778023487.589` 仅前 2 对通过累计门禁；`1777604354.022` 仅前 1 对通过，随后存在掩码缺失；`1778024078.588` 和 `1778024545.988` 均从首对开始未通过门禁。这些结果不足以支持在平台上自动固定整段标线。

首帧参照诊断显示存在显著漂移，且基于预测分割的分数可能受分割跳变、遮挡和相同类别虚线重复影响。需要同步的高质量位姿或人工跟踪路面控制点进行独立误差验证；在此之前不应将输出用作 BEV 几何真值。
