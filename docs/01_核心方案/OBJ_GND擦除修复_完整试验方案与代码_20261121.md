# OBJ/GND 背景恢复与重绘：现版试验方案

2026-11-21。仅提供本地代码和实施方案，无部署操作。当前接口/算法可能继续变化，接入时按函数调用定位，不整文件覆盖服务器。

## 1. 先按三种任务试，不再统一先擦除

| 任务 | 推荐路径 | 第一轮试验 |
|---|---|---|
| OBJ 新增 | 原图保留，在有效空间加入目标 | 10 帧、每帧一个锥桶，不删除车 |
| OBJ 替换 | 有真实背景观察才允许替换 | 5 个小目标，有邻帧显露背景；近处大货车先跳过 |
| GND 编辑 | 同位置改外观优先；改布局才需要恢复旧线背景 | 10 帧短线段，先做线宽/颜色，再试移动 |

你截图的货车占据大面积，背后道路、树木、杆件并未被观察；从单帧不能恢复可验证的真实内容。首轮不选这种替换样本。GND 的细丝状线条和穿车需要同时修绘制/投影与保护掩码，擦除算法单独升级解决不了。

## 2. 代码作用和边界

`background_trial.py` 是离线试验程序，输入原图、掩码、已对齐背景来源和目标图层，输出中间产物与质量报告。只依赖 Python、NumPy、OpenCV。

实现：新增模式免擦除；替换模式通过 donor 图像恢复背景；边界环做小幅颜色偏移和粗略一致性筛选；只改 erase 内像素；新图层线性空间合成；保护区不覆盖；背景缺观察就拒绝生成最终预览。所有试验保持 `training_eligible=false`。

**程序没有自动寻找/验证视频配准，没有加载生成式修复模型，也不生成 3D 素材或最终标签。** 这些输入必须来自现有平台或按下文准备。ring error 低只能筛掉部分明显错误，重复纹理、错误同色路面仍可能通过，不能证明背景正确。

## 3. 准备一帧输入

所有 target 侧掩码和 layer 必须与原图同宽高、同裁剪、同畸变域。禁止将 1600 预览掩码直接用于 1920 原图。

```text
trial/
  target.png                  原始实拍图，不带框/类别文字
  protected.png               白=保护，黑=可编辑：其他车辆/人/车头/路缘等
  allowed.png                 白=允许新图层显示的区域
  erase.png                   白=必须恢复的原实例/旧漆面；新增模式不需要
  layer.png                   同尺寸 BGRA；透明背景的新素材/标线
  donor01.png                 真实背景候选帧
  donor01_valid.png           白=确认是可用背景；动态物体/未知区域为黑
  replace.json
```

OBJ：erase 应为实例轮廓，不用整个检测矩形。旧目标的阴影是否移除需单独审核；若删除目标却留下明显旧影，样本不通过。protected 不包含准备删除的那个目标，但应包含其他不可动目标。

GND：erase 是可见漆面及必要的少量抗锯齿边缘，不是整条道路矩形。先用原图叠加检查分割是否对齐。车辆前景和车头必须从 erase 中排除。遮挡后的完整道路拓扑另外保存，不能从可见 mask 推断。

allowed：GND 必须限制在可见路面；OBJ 是其最终可见图层区域，不能简单只取路面——车身当然会延伸到路面以外。OBJ 接地点是否在合法路面应在放置阶段单独检查。深度/真实前景遮挡需要现有渲染适配器先处理；本程序 protected 仅提供保守保护。

## 4. 可直接运行的配置

新增 `add.json`：

```json
{
  "mode": "add",
  "target": "target.png",
  "protected": "protected.png",
  "allowed": "allowed.png",
  "layer": "layer.png"
}
```

替换 `replace.json`：

```json
{
  "mode": "replace",
  "target": "target.png",
  "protected": "protected.png",
  "allowed": "allowed.png",
  "erase": "erase.png",
  "layer": "layer.png",
  "max_ring_error": 20,
  "donors": [{
    "image": "donor01.png",
    "valid": "donor01_valid.png",
    "H_donor_to_target": [[1,0,0],[0,1,0],[0,0,1]]
  }]
}
```

**单位矩阵仅适用于已对齐的 donor**。不能给任意相邻视频帧填单位矩阵。矩阵必须是 donor 像素到 target 像素的方向。

在已有 NumPy/OpenCV 环境运行，无需安装 UE 或启动平台：

```bash
python -m unittest test_trial.py -v
python background_trial.py --config trial/add.json --out outputs/add_001
python background_trial.py --config trial/replace.json --out outputs/replace_001
```

输出目录必须不存在，避免覆盖。若本机无依赖，在单独虚拟环境安装 `numpy opencv-python`；不要升级生产环境。脚本读取路径相对于配置文件，不是当前 shell 目录。

## 5. 视频背景如何获得

第一阶段人工选 3–5 个邻近帧，时间跨度由场景运动决定。逐帧标记动态物体、未知与遮挡，不能拿当前车辆的另一帧当背景。

- 纯道路区域：用已验证相机/ego pose 和路面平面求配准，或者人工选取不少于 4 对不共线的道路点，用 OpenCV `findHomography` 估计。保留独立检查点，不能拿拟合点自证对齐。
- 非平面背景：道路、护栏、树木分别处理，或使用深度重投影。当前试验代码只支持每 donor 一个 H，因此仅用于局部近似平面、已审核区域。大货车跨多个平面的洞不适用。
- 可先将复杂配准的 donor 在其他工具中重投影到 target，导出对应 valid，再以单位矩阵交给脚本；valid 必须排除插值空洞和遮挡不确定区。
- 第一轮检查点对齐目标建议误差 ≤2px，属于试验起点；地平线附近/远处还需结合距离误差，不能一概承诺 2px 足够。
- donor 看不到的 erase 像素保留未知。脚本会拒绝输出 final；不要把 valid 全涂白绕过。

若没有可用 donor：换场景或改为新增。小范围缺口未来可加受控修复，但需要独立审核和跨帧一致性；不把 cv2/生成模型失败后静默回退当成功。

## 6. 现版具体接入位置

只在开发副本改，先完成上述离线试验。2026-11-21 只读核查到：

### OBJ：`/opt/ue5_synth/tools/pipeline_sim.py`

当前 `process_clip()` 调 `inpaint_objects(bg, obs)`，其内部 GrabCut 失败回退矩形、LaMa 失败回退 Telea。改成显式模式：

```python
mode = cfg.get('edit_mode', 'add')
if mode == 'add':
    clean = bg.copy()
    removed_list = []   # 与后续 build_frame_annotation 的实体处理一致
elif mode == 'replace':
    # reviewed erase/protected/donors 按 frame_id 从文件读取。
    clean, covered, diagnostic = restore(bg, erase, protected, donors)
    if np.any(erase & ~covered):
        # 写失败记录和中间产物；跳过本帧正式结果及训练导出。
        raise RuntimeError('background_restore_incomplete')
else:
    raise ValueError('unknown edit_mode')
```

真实工程里逐帧错误由外层捕获并写 frame status，不应让一个坏帧导致整批产物无记录。移除原始实体只能发生在替换已成功且标签更新完成之后。add 模式保留原始真实实体，不只改 clean 而继续使用旧 removed_list。

现版素材分支存在真实抠图素材路径；因此截图中的结果不应默认认定是 UE 渲染。前端和 manifest 应写 `renderer=real_sprite/ue/...`、asset_id、class、参数版本。选择 cone 而显示汽车需要核对执行记录与旧结果恢复逻辑。

### GND：`pipeline_gnd.py` 和 `pipeline_sim.py` 的 GND 分支

两条路径都必须修改，不能只改一个页面没调用的函数。将 `erase_lanes()` 的自动 LaMa/Telea 路径替换为审核后的背景恢复；同位置外观编辑尽量不挪几何。draw_lanes 应输出未压平的 BGRA 图层，交给 `composite()`，禁止先穿车画线再仅凭图像差值猜 alpha。

GND 线型先独立做合成素材测试：白底展示纹理、标明长度/宽度；投影 3m 实线+3m 间隔；检查近远处、横纵方向和标线侧边。如果原图中出现多条平行细丝，先停止批量，核对纹理行列、quad 角点顺序和多次叠画。

## 7. 前端最小调整

增加“新增/替换”模式，默认新增。替换流程分两步：先“背景恢复预览”，审核通过后再“生成素材”。显示 original / erase mask / restored / final 四个视图，框文字可关闭，支持原尺寸局部查看。

参数变化后旧结果显示旧版本标识，不能沿用它作为新参数结果。每次结果绑定 task_id + frame_id + source_image + config_hash + asset_id。刷新后从后端取真实状态，不依靠按钮文字推断。

## 8. 验收和试验放行

每张图检查：

1. erase 是否完整覆盖旧实例但没有误删保护区；影子是否合理。
2. restored 单独查看：有无模糊团、残边、重复纹理、道路断裂、结构缺失。
3. final 是否接地、尺寸合理、方向正确，光照/噪声/模糊与背景一致。
4. GND 不穿车、不穿车头，保留真实阴影，线宽/dash/gap 合理。
5. 连续播放是否闪烁、背景漂移；多相机需逐组验证。
6. 原始与合成标签正确合并，实例删除/遮挡更新和 GND 拓扑一致。

程序自动检查仅覆盖范围、保护区、粗略边界一致性；人工画面通过也不能取代标签/几何验证。试验结果默认不可训练，完整数据合同通过后由服务端独立导出门禁放行。

第一轮记录每种模式的成功率与拒绝原因，不只挑漂亮图。先做 25 帧上述小样；若无擦除新增明显更稳定，就优先用它扩充数据。恢复背景流程通过后，再做真实集 P/R 消融：真实基线、真实+新增、真实+替换，同训练预算和独立场景切分。

## 9. 实施顺序

- 第 1 步：1 天内完成配置与掩码/图层准备，跑通 add，确认背景零额外改动。
- 第 2 步：选小范围道路/目标替换，人工对齐 donor，跑 restore；无真实观察的样本拒绝。
- 第 3 步：修 GND 细丝投影和保护掩码，再测试替换。
- 第 4 步：现版开发副本接入两个 pipeline，补齐逐帧失败记录和标签处理。
- 第 5 步：通过黄金小样与连续播放，再扩批和训练验证。

时间是试验安排，不保证缺标定、标签或 donor 数据时也能完成。无需先部署新框架或重建全场景。


## 附录：完整可运行代码

```python
"""Offline background replacement trial. No network, models, UE or deployment.
Donor H maps donor pixels TO target pixels; all images must share image domain.
Only use geometry-aligned, reviewed donors. This program cannot establish truth.
"""
import argparse
import json
from pathlib import Path
import cv2
import numpy as np


def read_image(path):
    im = cv2.imread(str(path), cv2.IMREAD_COLOR)
    if im is None:
        raise ValueError('cannot read image: ' + str(path))
    return im


def read_mask(path, shape):
    m = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
    if m is None or m.shape != shape:
        raise ValueError('mask missing or wrong dimensions: ' + str(path))
    return m > 127


def linear(x):
    x = x.astype(np.float32) / 255
    return np.where(x <= .04045, x / 12.92, ((x + .055) / 1.055) ** 2.4)


def encoded(x):
    x = np.clip(x, 0, 1)
    s = np.where(x <= .0031308, x * 12.92, 1.055 * x ** (1/2.4) - .055)
    return np.rint(np.clip(s, 0, 1) * 255).astype(np.uint8)


def restore(target, erase, protected, donors, max_ring_error=20):
    """donors: [(BGR image, valid-background mask, H_donor_to_target)].
    No generative fallback. Unsupported pixels remain original and are flagged.
    """
    h, w = target.shape[:2]
    if erase.shape != (h,w) or protected.shape != (h,w):
        raise ValueError('target mask dimensions mismatch')
    if np.any(erase & protected):
        raise ValueError('erase overlaps protected region; fix masks first')
    ring = cv2.dilate(erase.astype(np.uint8), np.ones((11,11),np.uint8)) > 0
    ring &= ~erase & ~protected
    candidates=[];validities=[];diagnostics=[]
    for image, valid, H in donors:
        H=np.asarray(H,dtype=float)
        if H.shape != (3,3) or not np.isfinite(H).all() or abs(np.linalg.det(H)) < 1e-12:
            raise ValueError('invalid donor homography')
        if valid.shape != image.shape[:2]:
            raise ValueError('donor mask dimensions mismatch')
        warped=cv2.warpPerspective(image,H,(w,h),flags=cv2.INTER_LINEAR)
        # Linear validity prevents interpolation from mixing invalid foreground.
        v=cv2.warpPerspective(valid.astype(np.float32),H,(w,h),flags=cv2.INTER_LINEAR) > .999
        sample=ring & v
        if sample.sum() < 100:
            diagnostics.append({'accepted':False,'reason':'insufficient_reference_ring'})
            continue
        offset=np.median(target[sample].astype(float)-warped[sample],axis=0)
        offset=np.clip(offset,-15,15)
        corrected=np.clip(warped.astype(float)+offset,0,255)
        error=float(np.median(np.abs(target[sample].astype(float)-corrected[sample])))
        diagnostics.append({'accepted':error <= max_ring_error,'ring_error':error})
        if error > max_ring_error:
            continue
        candidates.append(corrected);validities.append(v)
    if not candidates:
        return target.copy(), np.zeros((h,w),bool), {'donors':diagnostics,'accepted_donors':0}
    stack=np.stack(candidates);valid=np.stack(validities)
    stack=np.where(valid[...,None],stack,np.nan)
    # Median only where donor observations exist; fill elsewhere with target.
    count=valid.sum(axis=0)
    stack[:,count==0,:]=target[count==0]
    median=np.nanmedian(stack,axis=0)
    covered=erase & (count>0)
    result=target.copy();result[covered]=np.rint(median[covered]).astype(np.uint8)
    return result,covered,{'donors':diagnostics,'accepted_donors':len(candidates)}


def composite(base, layer_bgra, allowed, protected):
    if layer_bgra is None or layer_bgra.shape != (*base.shape[:2],4):
        raise ValueError('layer must be target-size BGRA PNG')
    alpha=layer_bgra[...,3].astype(np.float32)/255
    alpha*=allowed & ~protected
    rgb=linear(base)*(1-alpha[...,None])+linear(layer_bgra[...,:3])*alpha[...,None]
    out=encoded(rgb)
    out[alpha==0]=base[alpha==0]  # exact preservation outside the edit
    return out,alpha


def run(config_path, out_dir):
    cfg_path=Path(config_path).resolve();cfg=json.loads(cfg_path.read_text(encoding='utf-8'))
    def path(s):
        p=Path(s);return p if p.is_absolute() else cfg_path.parent/p
    out=Path(out_dir)
    out.mkdir(parents=True,exist_ok=False)  # never silently overwrite a prior trial
    target=read_image(path(cfg['target']));shape=target.shape[:2]
    protected=read_mask(path(cfg['protected']),shape)
    allowed=read_mask(path(cfg['allowed']),shape)
    mode=cfg['mode'];covered=np.zeros(shape,bool);erase=np.zeros(shape,bool)
    diagnostics={};blockers=[]
    if mode=='add':
        clean=target.copy()
    elif mode=='replace':
        erase=read_mask(path(cfg['erase']),shape)
        if not erase.any():raise ValueError('empty replacement mask')
        donors=[]
        for d in cfg.get('donors',[]):
            image=read_image(path(d['image']))
            valid=read_mask(path(d['valid']),image.shape[:2])
            donors.append((image,valid,d['H_donor_to_target']))
        clean,covered,diagnostics=restore(target,erase,protected,donors,
                                          cfg.get('max_ring_error',20))
        if np.any(erase & ~covered):blockers.append('background_unobserved_pixels')
    else:raise ValueError('mode must be add or replace')
    cv2.imwrite(str(out/'original.png'),target)
    cv2.imwrite(str(out/'erase_mask.png'),erase.astype(np.uint8)*255)
    cv2.imwrite(str(out/'restored.png'),clean)
    cv2.imwrite(str(out/'background_coverage.png'),covered.astype(np.uint8)*255)
    # No final image if removal is incomplete: preserve diagnostic restoration only.
    if not blockers:
        layer=cv2.imread(str(path(cfg['layer'])),cv2.IMREAD_UNCHANGED)
        final,alpha=composite(clean,layer,allowed,protected)
        cv2.imwrite(str(out/'final_preview.png'),final)
        cv2.imwrite(str(out/'visible_alpha.png'),np.rint(alpha*255).astype(np.uint8))
    report={'mode':mode,'status':'rejected' if blockers else 'review_required',
            'training_eligible':False,'blockers':blockers,
            'erased_pixels':int(erase.sum()),'observed_background_pixels':int(covered.sum()),
            'diagnostics':diagnostics,
            'note':'coverage and ring agreement do not prove geometry or semantic correctness'}
    (out/'report.json').write_text(json.dumps(report,ensure_ascii=False,indent=2),encoding='utf-8')
    print(json.dumps(report,ensure_ascii=False,indent=2))
    return report


if __name__=='__main__':
    p=argparse.ArgumentParser();p.add_argument('--config',required=True);p.add_argument('--out',required=True)
    a=p.parse_args();run(a.config,a.out)

```
