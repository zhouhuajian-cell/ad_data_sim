## 0. 先确定技术路线：实拍场景为主体，渲染器可替换

用户转述的“把 3D 目标和 line 渲染到实拍场景”方向成立，但三个模块应采用不同方法：

| 模块 | 主路线 | 何时需要 3D | 关键约束 |
|---|---|---|---|
| TSR | 已有牌面上的图案替换；使用真实牌面几何投影 | 新增标牌、支杆、复杂姿态、多视角一致性需要牌面平面或 3D 模型 | 全部可见相机中语义一致；保留支架/底板/遮挡；牌面图案不能重绘错 |
| OBJ | 真实 PBR 3D 资产局部渲染 + 实拍底图 + 阴影/遮挡合成 | 默认需要 | 米制尺寸、位置、姿态、深度、接地、实例可见性与标签同源 |
| GND | 米制道路矢量/纹理，经标定投影到真实路面；平面场景使用 2.5D | 坡道、起伏、复杂遮挡和材质反射用道路网格/3D 渲染 | 同一条线在各相机、各时刻投影一致，保留道路拓扑 |

UE 是当前已经具备的渲染后端，不是平台中心。保留现有 UE 项目做 OBJ 资产/阴影渲染，首先把相机、真值、合成修正确；不要为了换引擎重建整套平台。Blender/Cycles 可作为离线小规模质量对照后端，是否采用由同一资产、同一相机、同一光照的对照结果决定。

**不重建整座真实城市**：只需要局部地面接收阴影、遮挡代理几何和插入目标。无需把实拍路面、树木、建筑全部换成 UE 场景。

单帧单目图无法保证恢复绝对尺度、遮挡顺序和光照。第一阶段优先采用真实标定、真实位姿/深度或人工复核的场景包。没有可靠标定的图，只进入 2D 实验池，不自动生成 BEV 3D 真值。

## 2. BEV 数据单位：一条 scene / 一个 clip，而不是孤立 JPG

### 2.1 必须从训练端确认并冻结的字段

- 相机列表与顺序、原始尺寸、畸变模型、K、相机到 ego 的变换、ego 到 world 的变换。
- 模型输入是否是多帧；窗口长度、采样间隔、相机实际时间戳；是否存在相机不同步。
- OBJ 的类别表、3D box 中心定义、尺寸顺序、yaw 定义、速度和可见性约定。
- GND 的线/面类别、采样密度、方向、实例与拓扑关系、BEV 感知范围。
- TSR 的粗类别、细类别、数值属性；哪些任务按牌面可读性计算监督。
- 若 BEV 同时使用 LiDAR/radar：不能只改图像却让点云显示空地。必须同步合成相应传感器或明确该数据仅用于相机分支实验。

本文内部采用右手世界坐标（米），相机坐标为 OpenCV 约定 `x右/y下/z前`，`T_cam_world` 把 world 点变换到 camera。生产 ego 坐标常为 `x前/y左/z上`，必须在入口转换，禁止凭字段名猜测轴向。

原图若有畸变：先按已有标定去畸变，在同一坐标下渲染与融合；若交付需要原始图，则连同新目标重新施加原畸变，标签同时映射。不要用无畸变投影直接贴到畸变图。

### 2.3 标签规则：必须合并真实标签

**只标新目标、忽略原图已有目标，会把真实目标变成训练负样本，这是 P/R 下降的高风险来源。**

- 插入：保留原真实标签，新增合成标签，更新被遮挡的原目标可见性。全遮挡目标如何计损失遵守训练端协议。
- 替换：明确绑定原 target/track ID；更新语义和属性；原牌 100 改 60，所有可见相机/时间帧都一致修改。
- 删除：必须修复所有视角/时刻的图像、阴影和标签，否则禁用该操作。
- 未标注或不确定的真实目标：补标或使用训练端真正支持的 ignore 区域；不能把未经校验的模型预测叫作真值。
- GND 虚线：区分物理可见线段与车道级中心线，不把每段虚线孤立当作一条无关联车道。
- 无新增目标的负样本也要交付，保持合理的背景分布；不能让模型学会“每张合成图必有目标”。

## 3. 最小可交付范围与实施顺序

不要同时扩展所有天气/全部资产。首批采用：有标定的干燥白天道路；TSR 清晰单牌；OBJ 锥桶和一类车辆；GND 实线/虚线/停止线。先形成端到端真实测试收益，再扩展遮挡、夜晚和湿地。

| 阶段 | 工作 | 退出条件 |
|---|---|---|
| A 可信数据 | 修标签、统一版本、全帧编号、场景划分、完整多相机/时序包 | 无错配；可复现；无源场景泄漏 |
| B 几何与真值 | 标定投影、接地、实例/深度、完整标签合并 | 同一世界目标跨相机/时间一致；真值与像素一致 |
| C 外观 | PBR 资产、TSR 牌面光照、GND 涂料纹理、阴影、相机成像 | 盲评与分场景检查胜过当前版；没有结构/语义损坏 |
| D 模型实验 | 真实基线、混入比例、模块消融、P/R 指标 | 固定 P 下 R 或固定 R 下 P 改善，重要类别无超限退化 |

首批可用每模块 100～200 个复核案例建立视觉/标签回归集；训练数据量通过真实验证集学习曲线决定，不能把这个抽检数量误当成足够训练的数据量。

## 5. 公共代码：标定投影与平面映射

此代码不依赖 UE。OBJ 渲染器、TSR 牌面投影、GND 标线投影必须共用相同标定。投影后超出图像的点不代表无效深度；由后续 rasterizer 裁剪。

```python
# file: synthkit/geometry.py
import cv2
import numpy as np


def checked_camera(K, T_cam_world):
    K = np.asarray(K, dtype=np.float64)
    T = np.asarray(T_cam_world, dtype=np.float64)
    if K.shape != (3, 3) or T.shape != (4, 4):
        raise ValueError("bad camera matrix shape")
    if not np.isfinite(K).all() or not np.isfinite(T).all():
        raise ValueError("camera contains NaN/Inf")
    if K[0, 0] <= 0 or K[1, 1] <= 0:
        raise ValueError("invalid focal length")
    if not np.allclose(K[2], [0, 0, 1]):
        raise ValueError("K must be a pinhole intrinsic matrix")
    if not np.allclose(T[3], [0, 0, 0, 1]):
        raise ValueError("bad homogeneous transform")
    R = T[:3, :3]
    if not np.allclose(R.T @ R, np.eye(3), atol=1e-5):
        raise ValueError("rotation is not orthogonal")
    if not np.isclose(np.linalg.det(R), 1.0, atol=1e-5):
        raise ValueError("reflection/scale in camera rotation")
    return K, T


def project(points_world, K, T_cam_world, near=0.10):
    K, T = checked_camera(K, T_cam_world)
    p = np.asarray(points_world, dtype=np.float64)
    if p.ndim != 2 or p.shape[1] != 3 or not np.isfinite(p).all():
        raise ValueError("points must be finite Nx3")
    camera = p @ T[:3, :3].T + T[:3, 3]
    z = camera[:, 2]
    valid = z > near
    uv = np.full((len(p), 2), np.nan, dtype=np.float64)
    q = camera[valid] @ K.T
    uv[valid] = q[:, :2] / q[:, 2:3]
    return uv, z, valid


def plane_homography(quad_world, texture_hw, K, T_cam_world):
    """quad order corresponds to texture TL, TR, BR, BL.

    Quad must be a convex planar quadrilateral. Distortion is handled outside.
    """
    q = np.asarray(quad_world, dtype=np.float64)
    if q.shape != (4, 3) or not np.isfinite(q).all():
        raise ValueError("quad must be finite 4x3")
    normal = np.cross(q[1] - q[0], q[3] - q[0])
    norm = np.linalg.norm(normal)
    if norm < 1e-9:
        raise ValueError("degenerate plane")
    if abs(np.dot(q[2] - q[0], normal / norm)) > 1e-4:
        raise ValueError("nonplanar quad: use road mesh instead")
    uv, _, valid = project(q, K, T_cam_world)
    if not valid.all():
        raise ValueError("plane crosses camera near plane")
    contour = uv.astype(np.float32).reshape(-1, 1, 2)
    if not cv2.isContourConvex(contour) or abs(cv2.contourArea(contour)) < 4:
        raise ValueError("invalid/subpixel projected quad")
    h, w = map(int, texture_hw)
    if min(h, w) < 2:
        raise ValueError("texture too small")
    src = np.float32([[0, 0], [w - 1, 0], [w - 1, h - 1], [0, h - 1]])
    H = cv2.getPerspectiveTransform(src, uv.astype(np.float32))
    return H


def seed_for(scene_id, track_id, global_seed=42):
    import hashlib
    key = (str(global_seed) + ":" + scene_id + ":" + track_id).encode("utf-8")
    return int.from_bytes(hashlib.sha256(key).digest()[:4], "little")
```

接入注意：真实 camera 外参若给的是 `T_ego_cam`，则 `T_cam_world = inverse(T_world_ego @ T_ego_cam)`。多相机不同步时，每个相机使用自己的时间戳查询 ego pose 和动态目标姿态，不能用同一个时间戳硬贴。

## 6. 公共代码：线性合成、阴影与 alpha

数组约定：RGB（不是 OpenCV 默认 BGR）；sRGB 图为 uint8；线性颜色为 float32；alpha 为 0～1；深度必须是 camera-Z 米制。背景 sRGB 逆变换得到的是合成工作空间，不能宣称恢复了传感器原始辐射。

```python
# file: synthkit/composite.py
import cv2
import numpy as np


def srgb_to_linear(rgb8):
    x = np.asarray(rgb8, np.float32) / 255.0
    return np.where(x <= 0.04045, x / 12.92, ((x + 0.055) / 1.055) ** 2.4)


def linear_to_srgb(x):
    x = np.clip(np.asarray(x, np.float32), 0, 1)
    y = np.where(x <= 0.0031308, 12.92 * x, 1.055 * x ** (1 / 2.4) - 0.055)
    return np.rint(np.clip(y, 0, 1) * 255).astype(np.uint8)


def visibility_from_depth(object_z, background_z, background_valid, margin_m=0.05):
    """Unknown depth is NOT automatically considered unobstructed.
    Return visible and uncertain; uncertainty requires review or other masks.
    """
    oz = np.asarray(object_z, np.float32)
    bz = np.asarray(background_z, np.float32)
    valid = np.asarray(background_valid, bool)
    if oz.shape != bz.shape or valid.shape != oz.shape:
        raise ValueError("depth shape mismatch")
    object_valid = np.isfinite(oz) & (oz > 0)
    known = valid & np.isfinite(bz) & (bz > 0)
    uncertain = object_valid & (~known | (np.abs(oz - bz) <= margin_m))
    visible = object_valid & known & (oz < bz - margin_m)
    return visible, uncertain


def compose_layers(bg_rgb8, fg_linear_rgb, alpha, shadow_transmittance, shadow_receiver):
    """fg is straight/unassociated alpha, already exposure/color matched.
    shadow_receiver must exclude real foreground objects not on receiving ground.
    """
    bg = srgb_to_linear(bg_rgb8)
    fg = np.asarray(fg_linear_rgb, np.float32)
    a = np.asarray(alpha, np.float32)
    tr = np.asarray(shadow_transmittance, np.float32)
    receiver = np.asarray(shadow_receiver, np.float32)
    if fg.shape != bg.shape or a.shape != bg.shape[:2]:
        raise ValueError("foreground shape mismatch")
    if tr.shape != a.shape or receiver.shape != a.shape:
        raise ValueError("shadow shape mismatch")
    for value in (fg, a, tr, receiver):
        if not np.isfinite(value).all():
            raise ValueError("nonfinite layer")
    for value in (a, tr, receiver):
        if value.min() < 0 or value.max() > 1:
            raise ValueError("mask/transmittance must be in [0,1]")
    atten = 1.0 - receiver * (1.0 - tr)
    base = bg * atten[..., None]
    out = linear_to_srgb(fg * a[..., None] + base * (1.0 - a[..., None]))
    # Preserve untouched pixels exactly before final image encoding.
    untouched = (a == 0) & (receiver * (1.0 - tr) == 0)
    out[untouched] = bg_rgb8[untouched]
    return out


def warp_rgba_linear(texture_rgba8, H, output_hw, blur_sigma=0.0):
    """Warp premultiplied color and alpha together to avoid black fringes."""
    texture = np.asarray(texture_rgba8)
    if texture.ndim != 3 or texture.shape[2] != 4 or texture.dtype != np.uint8:
        raise ValueError("texture must be uint8 RGBA")
    h, w = map(int, output_hw)
    alpha = texture[..., 3].astype(np.float32) / 255.0
    premult = srgb_to_linear(texture[..., :3]) * alpha[..., None]
    args = dict(dsize=(w, h), flags=cv2.INTER_LINEAR,
                borderMode=cv2.BORDER_CONSTANT, borderValue=0)
    a = cv2.warpPerspective(alpha, H, **args)
    p = cv2.warpPerspective(premult, H, **args)
    if blur_sigma > 0:
        a = cv2.GaussianBlur(a, (0, 0), blur_sigma)
        p = cv2.GaussianBlur(p, (0, 0), blur_sigma)
    straight = np.divide(p, np.maximum(a[..., None], 1e-6))
    straight[a <= 1e-6] = 0
    return straight, np.clip(a, 0, 1)


def overlay_surface(bg_rgb8, texture_rgba8, H, editable_mask, visibility,
                    illumination, blur_sigma=0.0):
    """For TSR faces/GND surfaces. No new geometric shadow is introduced here.

    illumination: calibrated scalar field or RGB gain in linear space.
    Editable mask and visibility must be registered to the target image.
    """
    shape = bg_rgb8.shape[:2]
    edit = np.asarray(editable_mask, np.float32)
    vis = np.asarray(visibility, np.float32)
    if edit.shape != shape or vis.shape != shape:
        raise ValueError("edit/visibility shape mismatch")
    if not np.isfinite(edit).all() or not np.isfinite(vis).all():
        raise ValueError("invalid masks")
    if min(edit.min(), vis.min()) < 0 or max(edit.max(), vis.max()) > 1:
        raise ValueError("masks must be in [0,1]")
    fg, a = warp_rgba_linear(texture_rgba8, H, shape, blur_sigma)
    light = np.asarray(illumination, np.float32)
    if light.shape == shape:
        light = light[..., None]
    if light.shape not in (shape + (1,), shape + (3,)):
        raise ValueError("illumination must be HxW or HxWx3")
    if not np.isfinite(light).all() or light.min() < 0:
        raise ValueError("invalid illumination")
    a *= edit * vis
    out = compose_layers(bg_rgb8, fg * light, a,
                         np.ones(shape, np.float32), np.zeros(shape, np.float32))
    return out, a
```

这段代码不自动猜光照、标定或遮挡。输入缺失时进入复核，不填全 1 然后标成生产通过。全 1 的 light/visibility 仅允许在已确认均匀光照、无遮挡的测试例中使用。

超小标牌/远处标线需使用超采样或 mipmap 再降采样，`warpPerspective` 的双线性插值不是完整抗锯齿方案。测试通过后才能把它扩展到远距离类别。

### 7.2 新的高质量路径

1. 利用已有标注/多视角定位或人工复核，确定牌面的世界四边形、track ID、目标类别。
2. 对每相机和时间戳计算 H。临时人工四角只可作为 2D 质量对照，不冒充世界几何。
3. 单牌同形状替换：编辑掩码限制在牌面内，原支杆、底板和真实遮挡保留。保留红圈时必须保证素材内圈与原圈比例一致。
4. 组合牌把底板与每块子牌绑定；只允许明确选择的子牌发生语义变化。所有相机同步更新。
5. 用原白底的可靠像素估低频照明场，排除文字、彩区、饱和/反光点；拟合平面/低阶曲面并限幅。不能把原图细节直接回贴，否则原数字会泄漏。
6. 用 `overlay_surface` 合成；最后统一相机模糊/编码。数字、字体、边框不得经过生成模型重绘。
7. 目标实例的精确类别由素材清单生成；可读性由目标像素大小、遮挡和任务规则决定。小牌不可读不等于不属于标牌检测正例。

TSR 原有“Gate4 检测不到则没有训练价值”的逻辑应取消。检测器只生成辅助 QC 分数；困难但标签可靠的样本是提升 R 的候选。模型加载失败、推理失败必须记 `unchecked`，不能记 `passed`。

## 8. OBJ：渲染器接口、资产与真实场景融合

### 8.1 资产要求

- 米制尺寸、统一原点（建议地面接触基点）、朝向、碰撞包围体；资产 bbox 与模型输出 bbox 定义显式转换。

- 车辆轮子实际接地；行人姿态与动作合理；远处 LOD 不得改变实例尺寸和类别。
- 素材 ID、版本、来源/使用范围、物理尺寸写资产清单。先少量高质量类别，不以大量代理模型填充训练集。
- 第一阶段先避开强透明物体、复杂镜面反射、湿地和极端夜景，这些需扩展合成模型。

### 8.2 渲染后端输入/输出契约

### 8.3 当前 UE 如何接入

主要改：`/data/avsynth/Content/Python/demo_obj_v4.py`。

- 删除随机相机/FOV作为生产默认的代码；从 manifest 设置真实相机投影与位姿。
- UE 为厘米、左手约定；上层为米、右手约定。写一个独立转换适配器，使用轴向标记板、棋盘格与多个已知点验证。不要只交换 Euler 角。
- 相机主点不居中、fx/fy 不等或存在 skew 时，单独设置 FOV 不足；需要匹配的投影矩阵或受控的过扫描与裁切。未支持的标定必须报错。
- RGB 输出先确认捕获源与颜色管理。现有 `FinalColorLDR` 不能仅因文件后缀是 EXR 就当作线性 HDR。
- 新增 instance/depth/coverage pass；所有 pass 使用完全一致的相机、时间、动画状态和分辨率。
- 曝光固定；beauty 可抗锯齿，分类 ID 禁止 TAA 混色；depth 采用明确无效值。静态多 pass 冻结对象与相机，动态场景以同一仿真时刻采样。
- 阴影接收面匹配真实地面；以实拍阴影和天空条件确定光照，不能仅根据整图对比度猜天气。

**以上 UE 适配是必须实施并实测的工作项，本文不把缺少项目资产/材质的伪代码标为可执行插件。** 现有 `batch_capture.py` 可复用渲染目标和捕获调度；ID/depth 材质必须在当前引擎版本验证。

UE 不是唯一选项。可另做 Blender/Cycles 小样后端，用透明 film、shadow catcher 和独立对象 pass 验证外观；相同输入/输出契约保证上层不绑定引擎。不要在本轮同时维护两个未经验证的生产实现。

### 8.4 阴影、深度与遮挡

- 合成真实前景遮挡：使用真实传感器深度或可信几何投影。单目深度仅作为提议，尺度不可靠时不得直接作为米制真值。
- `visibility_from_depth` 返回 uncertain 的区域进入复核；接地附近按 receiver/实例关系处理，不能简单在深度相等时任意留一层。
- 背景车辆/树木挡住新目标时，目标 ID 和可见掩码必须随图像一起裁剪。
- 新目标遮住旧目标时，旧 3D box/track 通常保留，更新 visible/occlusion 或 ignore；按训练协议执行。
- 阴影只施加到真实可见接收面。不能把地面阴影乘到前景行人/车辆上。
- 初版只支持不透明物体的直接遮挡和受影；倒影、玻璃透射、跨物体间接照明作为单独支持等级。

```python
# file: synthkit/truth.py
import copy
import numpy as np


def bbox_xywh(mask):
    ys, xs = np.where(np.asarray(mask, bool))
    if len(xs) == 0:
        return None
    x, y = int(xs.min()), int(ys.min())
    return [x, y, int(xs.max()) - x + 1, int(ys.max()) - y + 1]


def rle_uncompressed(mask):
    """COCO uncompressed RLE; includes holes and disconnected components."""
    a = np.asarray(mask, dtype=np.uint8)
    if a.ndim != 2:
        raise ValueError("mask must be HxW")
    values = (a > 0).reshape(-1, order="F")
    counts, current, length = [], False, 0
    for value in values:
        value = bool(value)
        if value == current:
            length += 1
        else:
            counts.append(length)
            length, current = 1, value
    counts.append(length)
    return {"size": list(a.shape), "counts": counts}


def instance_truth(instance_id, visible_ids, amodal_mask):
    ids = np.asarray(visible_ids)
    full = np.asarray(amodal_mask, bool)
    if ids.shape != full.shape or ids.ndim != 2:
        raise ValueError("mask shape mismatch")
    if not np.issubdtype(ids.dtype, np.integer) or instance_id <= 0:
        raise ValueError("categorical positive instance IDs required")
    visible = ids == instance_id
    # Passes must agree; do not silently intersect inconsistent captures.
    if np.any(visible & ~full):
        raise ValueError("visible instance extends outside amodal mask")
    full_area = int(full.sum())
    visible_area = int(visible.sum())
    if full_area == 0:
        raise ValueError("empty amodal mask")
    return {
        "instance_id": int(instance_id),
        "visible_bbox_xywh": bbox_xywh(visible),
        "amodal_bbox_xywh": bbox_xywh(full),
        "visible_area": visible_area,
        "amodal_area": full_area,
        "occlusion_in_frame": 1.0 - visible_area / full_area,
        "segmentation": rle_uncompressed(visible),
    }


def merge_labels(original_objects, replacements, additions, visibility_updates):
    """All objects use stable track_id. Changes are explicit, no inference.

    replacements: track_id -> full revised label; keep same track ID.
    visibility_updates: track_id -> per-camera/per-frame visibility fields.
    """
    result = copy.deepcopy(original_objects)
    index = {}
    for i, obj in enumerate(result):
        key = obj["track_id"]
        if key in index:
            raise ValueError("duplicate original track_id")
        index[key] = i
    for key, replacement in replacements.items():
        if key not in index or replacement.get("track_id") != key:
            raise ValueError("replacement target mismatch")
        result[index[key]] = copy.deepcopy(replacement)
    for key, update in visibility_updates.items():
        if key not in index:
            raise ValueError("visibility update for unknown real target")
        if set(update) - {"visibility_by_camera", "ignore_by_camera", "occlusion_by_camera"}:
            raise ValueError("visibility update must not overwrite semantic/geometry labels")
        result[index[key]].update(copy.deepcopy(update))
    for obj in additions:
        key = obj["track_id"]
        if key in index:
            raise ValueError("synthetic track_id collision")
        index[key] = len(result)
        result.append(copy.deepcopy(obj))
    return result
```

`occlusion_in_frame` 分母只涵盖画面内 amodal 掩码，不等于画幅外截断率。单独保存 truncation，并按训练协议决定二者用途。完全遮挡实例的 visible bbox 为 `None`，不能生成零宽伪框。原有 3D box 来自场景几何，不由 2D mask反推。

## 10. GND：真实路面的米制矢量投影

### 10.1 首选 2.5D 的条件

平坦路面、可信相机/地面标定、普通白/黄标线时，不需要为每条线启动 UE。直接用米制图案的世界四角求 H，投影到原图，再按可见性、路面照明和纹理融合。

坡道或起伏使平面假设失效时，把道路表示为网格，在表面坐标中铺线并由后端渲染；不通过无限调 H 勉强贴合。夜间逆反射/湿地高光需要额外材质模型，不能用常量自发光替代。

### 10.2 可执行的纹理和矢量采样代码

磨损在同一条道路/线实例的物理坐标内生成。多相机/多帧复用同一份纹理；不要每帧重新随机。以下代码生成一条矩形标线的纹理，完整道路由矢量实例组合。

```python
# file: synthkit/ground.py
import cv2
import numpy as np


def paint_texture(length_m, width_m, pixels_per_m, seed,
                  rgb=(215, 213, 201), wear=0.15, dashed=None):
    """Rows follow line length, columns follow width.
    dashed=(dash_m, gap_m); physical numbers come from dataset specification.
    This is diffuse paint coverage, not a retroreflection model.
    """
    if min(length_m, width_m, pixels_per_m) <= 0 or not 0 <= wear <= 1:
        raise ValueError("invalid physical paint parameters")
    h = max(2, int(round(length_m * pixels_per_m)))
    w = max(2, int(round(width_m * pixels_per_m)))
    if h * w > 16000000:
        raise ValueError("texture too large; tile in world coordinates")
    rng = np.random.default_rng(seed)
    # Correlated damage + fine pigment variation, both stable on this surface.
    coarse = rng.random((max(2, h // 24), max(2, w // 8))).astype(np.float32)
    field = cv2.resize(coarse, (w, h), interpolation=cv2.INTER_CUBIC)
    field = np.clip(field, 0, 1)
    fine = rng.random((h, w)).astype(np.float32)
    density = 0.8 * field + 0.2 * fine
    alpha = np.clip((density - wear * 0.65) / 0.12, 0, 1)
    edge_distance = np.minimum(np.arange(w), np.arange(w)[::-1])[None, :]
    alpha *= np.clip(edge_distance / max(1.0, w * 0.035), 0, 1)
    if dashed is not None:
        dash, gap = map(float, dashed)
        if dash <= 0 or gap <= 0:
            raise ValueError("dash/gap must be positive meters")
        s = (np.arange(h) + 0.5) / pixels_per_m
        alpha *= ((s % (dash + gap)) < dash)[:, None]
    rgba = np.empty((h, w, 4), dtype=np.uint8)
    variation = 0.94 + 0.06 * fine[..., None]
    rgba[..., :3] = np.clip(np.asarray(rgb)[None, None, :] * variation, 0, 255)
    rgba[..., 3] = np.rint(alpha * 255).astype(np.uint8)
    return rgba


def sample_polyline(points_xyz, step_m=0.25):
    p = np.asarray(points_xyz, np.float64)
    if p.ndim != 2 or p.shape[1] != 3 or len(p) < 2 or step_m <= 0:
        raise ValueError("need finite Nx3 polyline and positive step")
    if not np.isfinite(p).all():
        raise ValueError("invalid polyline")
    keep = np.r_[True, np.linalg.norm(np.diff(p, axis=0), axis=1) > 1e-8]
    p = p[keep]
    if len(p) < 2:
        raise ValueError("zero length line")
    s = np.r_[0.0, np.cumsum(np.linalg.norm(np.diff(p, axis=0), axis=1))]
    target = np.r_[np.arange(0, s[-1], step_m), s[-1]]
    return np.stack([np.interp(target, s, p[:, k]) for k in range(3)], axis=1)
```

用法：以线实例 ID 得到 `seed_for(scene, line_id)`；生成一次 RGBA；按每相机的 H 调用 `overlay_surface`。若长度方向与 quad 顺序不同，调整纹理角点映射，不靠试图翻转解决。

### 10.3 材质/光照接入

- 从可信路面区域估计低频照明场，原有阴影保留；不能把旧白线当作路面照明样本。
- 保留路面颗粒的适度高频变化，但不要把原有标线/文字纹理混入新线。
- 标线不完全不透明，磨损孔洞直接露出原路面。颜料覆盖率与几何 mask 分开保存，标注协议明确磨损到什么程度仍算线。
- 新增线不得未经规则校验形成冲突驾驶语义；替换旧线必须先清理旧线并复核修复结果，否则只允许在无旧线区域新增。
- 样条的曲率、宽度、虚实节律随世界位置定义；避免逐像素随机纹理和整条均匀缩窄。

```python
# file: synthkit/delivery.py
import hashlib
import json
import os
import shutil
import tempfile
from pathlib import Path


def safe_name(value):
    if not value or any(c not in "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789_-" for c in value):
        raise ValueError("unsafe identifier")
    return value


def publish_frame(root, frame_id, artifacts, annotation):
    """artifacts is {simple_filename: bytes}. Publish once; never overwrite.
    Parent job directory must have one writer/claim per frame.
    """
    root = Path(root)
    root.mkdir(parents=True, exist_ok=True)
    frame_id = safe_name(frame_id)
    target = root / frame_id
    if target.exists():
        raise FileExistsError(str(target))
    staging = Path(tempfile.mkdtemp(prefix="." + frame_id + "_", dir=str(root)))
    try:
        hashes = {}
        for name, data in artifacts.items():
            if Path(name).name != name or name in ("", ".", "..", "annotation.json", "complete.json"):
                raise ValueError("artifact name must be an ordinary leaf filename")
            if "/" in name or "\\" in name or ":" in name:
                raise ValueError("unsafe artifact filename")
            if not isinstance(data, bytes) or not data:
                raise ValueError("artifact must be nonempty bytes")
            with (staging / name).open("xb") as f:
                f.write(data)
                f.flush()
                os.fsync(f.fileno())
            hashes[name] = hashlib.sha256(data).hexdigest()
        payload = json.dumps(annotation, ensure_ascii=False, allow_nan=False).encode("utf-8")
        (staging / "annotation.json").write_bytes(payload)
        hashes["annotation.json"] = hashlib.sha256(payload).hexdigest()
        (staging / "complete.json").write_text(json.dumps({"files": hashes}), encoding="utf-8")
        # Same-filesystem directory rename; only complete packages become visible.
        # Worker claim guarantees no concurrent writer for this frame.
        os.rename(str(staging), str(target))
        return target
    except Exception:
        shutil.rmtree(str(staging), ignore_errors=True)
        raise


def completion(expected_ids, states):
    expected = set(expected_ids)
    unexpected = set(states) - expected
    if unexpected:
        raise ValueError("unexpected output IDs")
    counts = {"PASSED": 0, "REJECTED": 0, "FAILED": 0, "MISSING": 0, "PENDING": 0}
    for fid in expected:
        state = states.get(fid, "MISSING")
        if state not in counts:
            raise ValueError("unknown frame state: " + state)
        counts[state] += 1
    all_passed = counts["PASSED"] == len(expected) and len(expected) > 0
    return {"total": len(expected), "counts": counts,
            "status": "SUCCEEDED" if all_passed else "INCOMPLETE_OR_REJECTED"}
```

此原子发布防止 UI 读到半成品，不代替数据库 claim，也不宣称断电级持久化。上电恢复时检查 complete.json 与所有哈希；元数据 fsync/目录 fsync、网络盘 rename 语义在生产文件系统单独验证。文件发布后 DB 更新失败时，通过恢复扫描补齐状态。

### 11.3 作业管理改造

保留 SQLite；增加 `QUEUED/RUNNING/RENDERED/COMPOSITED/QUALITY_REVIEW/PASSED/FAILED/CANCELLED` 状态和 lease。HTTP 只入队，不直接运行 UE。claim 必须事务化，避免两个 worker 同时获取一条作业。

```sql
-- 新表建议；不要在无备份条件下直接改当前表。
CREATE TABLE IF NOT EXISTS work_items_v2 (
  item_id TEXT PRIMARY KEY,
  job_id TEXT NOT NULL,
  frame_id TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'QUEUED',
  worker_id TEXT,
  lease_until REAL,
  attempt INTEGER NOT NULL DEFAULT 0,
  error_code TEXT,
  manifest_json TEXT NOT NULL,
  UNIQUE(job_id, frame_id)
);
CREATE INDEX IF NOT EXISTS work_status_v2 ON work_items_v2(status, lease_until);
-- claim: BEGIN IMMEDIATE -> SELECT QUEUED -> UPDATE with worker + lease -> COMMIT

```

- 一个统一 GPU 调度入口：UE、TSR 模型、深度/分割模型均登记资源；初期 GPU 重任务串行，CPU 后处理可并发。
- 统一锁文件代替目前小样/批量不同锁；任务锁定范围覆盖整个 GPU 子进程组生命周期。
- `subprocess.Popen(argv, shell=False, start_new_session=True)`；超时/取消按进程组 TERM、宽限、KILL；不能只杀 `flock` 外壳。
- 心跳、实际 PID/进程启动时间、lease 同时记录。服务重启不自动复制一份运行中的 UE。
- 指数退避最多有限次数，配置错误/素材缺失不重试；崩溃重试只处理未完成帧。
- 日志、缩略图、原始 EXR 分生命周期管理。质量失败要保留少量可诊断样本，不把所有大 EXR 永久堆积。

## 12. 前端交互：快反馈和结果一致性

页面必须展示场景/clip，而不是仅展示互不相关图片；多相机联动选择同一目标，时间轴固定 track ID；3D/BEV 视图显示目标位置和投影一致性。

预览分两级：快速草稿用于调位置，明确水印；最终预览使用生产标定、资产、种子和质检。草稿不能进入交付目录。

### 12.1 滑块防抖、取消请求、防迟到覆盖

```javascript
// file: dashboard/preview_controller.js
// send(body, signal) is an adapter for the existing or new preview endpoint.
// render(result) must resolve only after the corresponding image is ready.
export function createPreviewController({ send, render, showError, delay = 300 }) {
  let timer = null;
  let controller = null;
  let revision = 0;
  let disposed = false;
  return {
    request(body) {
      if (disposed) return;
      const rev = ++revision;
      clearTimeout(timer);
      controller?.abort();
      timer = setTimeout(async () => {
        controller = new AbortController();
        const signal = controller.signal;
        try {
          const result = await send(body, signal);
          if (disposed || signal.aborted || rev !== revision) return;
          // render must also check isCurrent before committing a decoded image.
          await render(result, () => !disposed && rev === revision && !signal.aborted);
        } catch (error) {
          if (error.name !== "AbortError" && rev === revision && !disposed) {
            showError(error.message);
          }
        }
      }, delay);
    },
    dispose() {
      disposed = true;
      ++revision;
      clearTimeout(timer);
      controller?.abort();
    }
  };
}
```

浏览器 abort 只取消 HTTP 等待，不保证后端停止计算。服务端使用 `client_session + revision` 合并尚未运行的预览作业；只有当前会话自己的过期预览可取消，不能取消批量作业。

### 12.2 后端与缓存

- 提交返回 202 + job_id；参数严格白名单和范围校验；未接入参数报错，不静默忽略。
- cache key 包含源图/场景哈希、标定、资产、渲染器版本、参数、种子、相机、时间戳；不能只用参数或文件名末尾。
- 静态内容/不可变结果按内容哈希长缓存；状态接口短缓存或不缓存；分开处理。
- 缩略图生成 320/640 像素版本，首屏只加载可视项；原图按需加载，结果比较同步缩放/平移。
- 列表分页、稳定 key、局部更新；切换页面停止轮询；状态请求串行自调度，避免网络慢时 setInterval 堆积。
- 同一轨迹跨相机/帧的修改先预览，保存为新版本，不原地覆盖训练产物。

建议目标（不是已测值）：内网首屏可操作 p95 ≤2s；任务提交响应 p95 ≤500ms；缓存缩略图切换 ≤200ms。单独记录排队、渲染、合成、质检耗时。

## 13. 质量门控：不让错误标签换来表面通过率

| 层级 | 检查 | 处理 |
|---|---|---|
| 契约 | 文件完整、相机同步、坐标/单位/类别有效、标签闭合 | 不合格直接拒绝 |
| 几何 | 多视角投影、接地、尺寸、穿插、可见性/实例一致 | 不确定进入人工复核 |
| 语义 | 原目标确实是牌/车/标线，替换后的数值/类别和拓扑正确 | 无可靠真值不得自动交付 |
| 成像 | 边缘、阴影、曝光、材质、压缩、纹理与背景一致 | 分项评分，与真实参考对照 |
| 模型 | 检测器/BEV 输出、置信度、误检/漏检样例 | 用于诊断和样本选择，不作唯一真实性门槛 |

不要设一条“目标 <24px 全部拒绝”作为训练数据默认规则。小目标是 R 的重要来源；小目标应降低细属性监督或转人工审核，是否保留由任务协议决定。

不以“通过率越高越好”验收；应同时汇报原始候选数、失败原因、复核数、有效类别/距离覆盖和最终可训练样本数。

## 14. P/R 实验设计：最终决定数据是否交付

### 14.1 划分和泄漏控制

1. 在合成之前按原始 scene/路线/采集片段划分 train/val/test；相邻帧与同一场景的变体不能跨集合。
2. 独立真实 test 不参与素材裁取、参数标定、阈值选择或人工作为反复调参依据。
3. 同一场景生成的 1000 张变化不能按 1000 个独立样本计算统计置信度；按 scene bootstrap。
4. 资产/天气/距离分布单独记录；训练、验证之间使用有意义的资产隔离，防止只记住少数渲染资产。

### 14.2 推荐实验矩阵

| 实验 | 数据 | 目的 |
|---|---|---|
| R0 | 原真实训练集 | 基线 |
| R1 | 相同真实数据，重复采样到相同训练步数 | 排除仅多训练导致的收益 |
| T | 真实 + TSR 合成 | TSR 和 BEV 其他头影响 |
| O | 真实 + OBJ 合成 | OBJ 改善与误检变化 |
| G | 真实 + GND 合成 | 车道召回/拓扑与其他头影响 |
| ALL | 真实 + 三模块 | 联合增益与负迁移 |

初始合成样本采样比例试 5%、10%、20%；比例按训练 batch 的采样占比定义。优化器、训练步数、增强、模型初始化和评测代码保持一致；先做小规模筛选，再对候选配置用至少 3 个训练种子验证。模型支持多任务损失时，监控各头损失和梯度冲突，不只观察总损失下降。

### 14.3 指标定义必须按头匹配

- OBJ：在真实 BEV 中按类、中心距离/3D IoU等既定协议做一对一匹配；分别看远近、大小、遮挡、速度分桶。
- TSR：牌面/3D 目标检测的 P/R 与细类/限速值正确率分开；分类错误不能算成正确检测收益。还需检查跨相机同一牌是否一致。
- GND：按既定曲线距离/覆盖率/方向阈值匹配 line/lane 实例；同时看拓扑错误、断裂、虚实混淆；不能套普通 2D box IoU。
- Precision = TP/(TP+FP)，Recall = TP/(TP+FN)。必须报告置信阈值、匹配阈值和评测范围。
- 主报告：固定 Precision 下 Recall；固定 Recall 下 Precision；另报完整 PR/AP 和生产阈值下 P/R。阈值只在真实 val 上选定，再锁定到真实 test。
- 场景级误报密度（每公里/每帧）与漏检关键案例作为补充，避免平均指标掩盖严重问题。

### 14.4 已匹配预测的 P/R 计算模块

下面模块不替代 OBJ/TSR/GND 匹配器。输入 `tp` 必须由各头正式 matcher 生成，每个 GT 最多匹配一次，ignore/crowd 已按协议处理。不能拿 YOLO 置信度直接当 TP。

```python
# file: synthkit/pr_eval.py
import numpy as np


def pr_curve(scores, true_positive, n_gt):
    scores = np.asarray(scores, np.float64)
    tp = np.asarray(true_positive)
    if scores.ndim != 1 or tp.shape != scores.shape or n_gt < 0:
        raise ValueError("invalid matched prediction inputs")
    if not np.isfinite(scores).all() or not np.isin(tp, [0, 1]).all():
        raise ValueError("scores must be finite and TP must be binary")
    if int(tp.sum()) > n_gt:
        raise ValueError("duplicate GT matching or wrong n_gt")
    if n_gt == 0:
        return []  # R undefined; report FP separately for negative-only slices.
    order = np.argsort(-scores, kind="stable")
    s = scores[order]
    hit = tp[order].astype(np.int64)
    ctp = np.cumsum(hit)
    if len(s) == 0:
        return []
    # Group equal scores: a threshold cannot include only part of a tie.
    ends = np.r_[np.where(s[:-1] != s[1:])[0], len(s) - 1]
    rows = []
    for i in ends:
        found = int(ctp[i])
        rows.append({"threshold": float(s[i]), "tp": found,
                     "fp": int(i + 1 - found), "fn": int(n_gt - found),
                     "precision": found / float(i + 1), "recall": found / float(n_gt)})
    return rows


def select_on_validation(rows, precision_floor=None, recall_floor=None):
    if (precision_floor is None) == (recall_floor is None):
        raise ValueError("choose exactly one operating constraint")
    if precision_floor is not None:
        if not 0 <= precision_floor <= 1:
            raise ValueError("invalid precision floor")
        valid = [r for r in rows if r["precision"] >= precision_floor]
        return max(valid, key=lambda r: (r["recall"], r["precision"])) if valid else None
    if not 0 <= recall_floor <= 1:
        raise ValueError("invalid recall floor")
    valid = [r for r in rows if r["recall"] >= recall_floor]
    return max(valid, key=lambda r: (r["precision"], r["recall"])) if valid else None


def at_locked_threshold(scores, true_positive, n_gt, threshold):
    # Validate all inputs and matching before applying the locked val threshold.
    pr_curve(scores, true_positive, n_gt)
    scores = np.asarray(scores, np.float64)
    hit = np.asarray(true_positive, dtype=np.int64)
    keep = scores >= threshold
    count = int(keep.sum())
    tp = int(hit[keep].sum())
    return {"threshold": float(threshold), "tp": tp, "fp": count - tp,
            "fn": int(n_gt - tp),
            "precision": tp / count if count else None,
            "recall": tp / n_gt if n_gt else None}
```

### 14.5 建议交付准入门槛

P/R 的业务目标值由模型负责人填写，不替用户编造“必须提升 5%”。至少满足：

- 真实 test 主指标有稳定改善，重要类别和关键场景退化不超过预先约定容忍度。
- 多个训练种子结果方向一致，场景级置信区间支持结论；不要用一次随机训练的 0.1 点变化宣称有效。
- 真实与合成混入比例已经在 val 选择，test 只作锁定评估。
- 标签错误抽检、几何错误、跨相机不一致和源场景泄漏达到预设门槛；发现系统性错误则整批退回。
- 数据交付物带版本、校验和、类别分布、过滤/复核记录、训练配置、锁定阈值和分桶 P/R。

## 16. 现场集成验收：必须执行的测试清单

### 几何/真值

- 使用已知尺寸的标定板/立方体，在每相机选择多个近远位置；验证投影和单位。记录像素误差与 BEV 米制误差，阈值按真实标定误差设定。
- 同一目标位于两个相机重叠区，观察中心、朝向、尺寸及遮挡一致性。
- 同一静态标牌/标线随 ego 运动不漂移；动态车辆轨迹、速度和各相机时间采样一致。
- 纯黑轮胎、细杆仍有正确 instance ID；强阴影不产生伪实例；两物体相互遮挡时 ID 与深度一致。
- 一像素宽实例 bbox 不为 0；完全遮挡实例没有伪可见框；所有原真实标签仍存在。
- GND 曲线/坡道不能被平面 warp 悄悄接收；画外截断与物体遮挡分别统计。

### 外观

- TSR：细字形、红圈厚度、旧边残留、组合牌、过曝与阴影；查看原尺寸与放大局部，避免只看缩略图。
- OBJ：车轮接地、比例、车窗/车漆、阴影方向、暗部完整性、遮挡边缘；固定底图/资产对照不同渲染版本。
- GND：非自发光、真实磨损孔洞、路面颗粒、远处抗锯齿、曲率/宽度一致、旧线残影。
- 编码前后各验一次；保持实际交付分辨率，不能只验证高清渲染再交付低清 JPEG。
- 生成模型若作为实验局部润色，保护几何/语义 mask；润色后重新检验标签，默认不用于牌面数字和线拓扑。

### 稳定性/交互

- 帧数分别跨越 chunk 边界，例如 99、100、101；核对唯一 ID 与产物数，禁止覆盖。
- 中断 UE、worker、HTTP 服务各一次；恢复后不重复发布、不漏算缺帧。
- 提交重复作业、重复点击、取消、磁盘不足、模型不可用、网络盘断开；结果状态必须准确。
- 快速连续拖动参数/切换相机，旧请求不得覆盖新结果；后台任务不因前端切页而丢失。
- 人为生成不完整帧包，UI/导出不应显示为可交付；complete 哈希不一致时隔离。

- [CVPR 2021：Repopulating Street Scenes](https://openaccess.thecvf.com/content/CVPR2021/papers/Wang_Repopulating_Street_Scenes_CVPR_2021_paper.pdf)：街景插入同时涉及尺度、遮挡、光照和阴影；本方案采用相同问题分解，但不声称复现其模型或效果。

当前版本最大的收益机会是修正几何/标签与真实图像之间的关系，再提高资产和成像质量。最终选择技术路线的依据是独立真实测试集上的 P/R 与关键场景表现，而不是引擎名称、渲染分辨率或单张图片的视觉冲击力。

## 20. 快速提取代码与本地验证记录

### 20.1 开发者如何从文档提取代码

把下面脚本另存为 `extract_candidate.py`，它只提取有 `file:` 标记的完整代码块。目标目录必须不存在，避免覆盖现有代码；不会部署到服务器。

```python
import pathlib
import re
import sys

document = pathlib.Path(sys.argv[1]).resolve()
destination = pathlib.Path(sys.argv[2]).resolve()
if destination.exists():
    raise SystemExit("目标目录已存在，请使用新的候选目录")
text = document.read_text(encoding="utf-8")
payloads = []
for language, code in re.findall(r"```(python|javascript)\n(.*?)\n```", text, re.S):
    header = code.splitlines()[0]
    match = re.fullmatch(r"(?:#|//) file: ([A-Za-z0-9_./-]+)", header)
    if not match:
        continue
    relative = pathlib.PurePosixPath(match.group(1))
    if relative.is_absolute() or ".." in relative.parts:
        raise SystemExit("代码路径非法")
    if language == "python":
        compile(code, str(relative), "exec")
    payloads.append((relative, code))
if len({str(p) for p, _ in payloads}) != len(payloads):
    raise SystemExit("重复代码路径")
if not payloads:
    raise SystemExit("未找到完整模块")
destination.mkdir(parents=True)
for relative, code in payloads:
    target = destination.joinpath(*relative.parts)
    target.parent.mkdir(parents=True, exist_ok=True)
    with target.open("x", encoding="utf-8") as output:
        output.write(code + "\n")
(destination / "synthkit" / "__init__.py").touch(exist_ok=False)
print("已提取 %d 个代码文件到 %s" % (len(payloads), destination))
```

执行方式（候选路径自行选择，不使用生产输出目录）：

```text
python extract_candidate.py "本文档的完整路径.md" "新的候选目录"
cd 新的候选目录
python -m unittest discover -s tests -v
```

现有脚本的接入片段必须人工合并，保留原有必要字段、异常计数和记录，不直接用简化片段替换整个生产函数。JS controller 需要 API 适配器；它不是现有页面可直接引用即完成的完整前端改造。
