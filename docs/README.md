# 文档目录

本目录按用途归类。带日期的方案、操作步骤和验收结论是当时的记录；平台持续更新，运行前请结合服务器当前代码、任务记录及版本信息核实，不能把历史方案视为已经实现或通过生产验收。

## 当前入口

- [项目介绍与运行环境](../README.md)：平台总体说明；部分操作与参数为历史记录，部署时以当前服务为准。
- [版本管理说明](../VERSIONING.md)：版本号和发布记录规则；平台当前版本可在页面或 `/api/platform/versions` 查询。
- [数据交付格式](DATA_FORMAT_SPEC.md)：原始数据和输出字段参考。使用前应结合实际任务标注、坐标系和质量门禁验证。
